Understanding Application-Specific Codes vs HTTP Codes

HTTP status codes (such as 400, 404, or 500) represent transport and protocol-level responses between the client and web server. In contrast, APP-001 is an internal application-level code used within Fitora to signal specific business-logic scenarios—such as nutrition calculation overflow or automated fallback to the local PostgreSQL database when an external nutrition API times out.
